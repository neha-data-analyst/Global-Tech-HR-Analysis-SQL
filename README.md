
# E-Commerce Sales Analysis using SQL

## Project Overview
This project focuses on analyzing e-commerce sales data using SQL and Google BigQuery.

The objective is to explore sales performance, customer behavior, product trends, and business insights using SQL queries.

## Objectives
- Analyze overall sales performance.
- Identify top-performing products.
- Understand customer purchasing behavior.
- Analyze monthly sales trends.
- Generate actionable business insights.

## Tools Used
- Google BigQuery
- SQL
- GitHub

## SQL Concepts
- SELECT and WHERE
- GROUP BY and HAVING
- Joins
- Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- Aggregate Functions
